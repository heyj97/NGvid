# 진행 상황과 결정 사항

기능개발문서의 마일스톤 기준. 마일스톤을 끝낼 때마다 갱신한다.

## 마일스톤

| 마일스톤 | 상태 | 비고 |
| --- | --- | --- |
| M0 기반 세팅 | 완료 | |
| M1 재생 엔진 | 완료 | `FrameCache`는 만들지 않음 (탐색이 느려지면 추가) |
| M2 리소스 보관함 | 완료 | 미디어 다시 연결은 별도 창 대신 보관함 안의 안내와 메뉴로 구현 |
| M3 타임라인 | 완료 | |
| M4 컷편집 | 완료 | |
| M5 오디오 | 완료 | |

| M9 텍스트·자막 | 완료 | 자막 효과 편집기 창은 만들지 않음: 등장 효과는 애니메이션 프리셋, 강조 효과는 단어 강조 색으로 대신함. 가져온 자막은 새 자막 트랙에 들어감 |
| M10 전환·효과·색보정 | 완료 | 별도의 효과 패널(끌어 놓기)은 만들지 않고 속성 패널의 전환·효과·색보정 항목으로 대신함 |
| M11~M13 | 예정 | 크로마키·마스크, 속도, 마무리 |

## 직접 확인이 필요한 것

자동 테스트와 메뉴·버튼 자동 조작으로는 확인했지만, 사람이 직접 해 봐야 하는 것들이다.

- **마우스 조작**: 타임라인 눈금을 눌러 탐색, 클립을 끌어 이동, 양끝을 잡아 트리밍, Ctrl+클릭 다중 선택,
  Ctrl+휠 확대, 보관함에서 타임라인으로 끌어 놓기, 트랙 머리와 마커의 오른쪽 클릭 메뉴.
  (자동 시험이 실제 마우스를 움직이면 사용 중인 화면을 건드리므로 하지 않았다.)
- **소리**: 볼륨, 페이드, 자동 감쇠, 음소거·솔로가 귀로 듣기에 맞는지. 수치로는 테스트했다.
- **실제 촬영본**: 휴대폰 영상(가변 프레임레이트), 4K, 긴 영상의 재생·탐색 속도.
- **파일 대화상자**: 새 프로젝트, 열기, 미디어 가져오기, 다시 연결, 내보낼 파일 고르기.
- **첫 실사용 (M6 완료 기준)**: 실제 영상 1편을 컷편집해서 내보내고, 미리보기와 결과물이 같은지 눈과 귀로 비교하기.
- **미리보기 직접 조작**: 미리보기에서 클립을 끌어 옮기기, 휠로 크기 바꾸기. (키프레임이 있는 속성은 끌어도 바뀌지 않으니 속성 패널에서 고친다.)
- **텍스트·자막**: 글꼴 고르기, 자막 목록 창에서 칸을 직접 고치기, SRT·VTT 가져오기와 SRT 내보내기(파일 대화상자), 스타일 프리셋 저장·삭제.
- **효과·색보정·전환**: 값에 따른 화면 변화가 눈으로 보기에 적당한지, LUT 불러오기(파일 대화상자), 전환이 재생 중에 매끄러운지.
- **애니메이션**: 키프레임으로 만든 움직임과 이징이 눈으로 보기에 자연스러운지, 프리셋 저장·삭제(이름 입력 창).
- **내보내기 속도**: 화면 합성을 CPU로 하므로 긴 영상에서 얼마나 걸리는지.

## 권장안으로 정하고 진행한 것

| 항목 | 정한 내용 |
| --- | --- |
| 트랙 합성 순서 | 목록의 위쪽 트랙이 화면에서도 위에 그려진다 |
| 텍스트·이미지 클립 | 영상 트랙에 놓는다 |
| 같은 트랙의 클립 겹침 | 허용하지 않는다. 다른 클립 위로 옮기면 끼워 넣는다 |
| 끼워 넣기 규칙 | 옮긴 클립이 상대 클립의 앞쪽 절반에 걸치면 그 앞에, 뒤쪽 절반이면 그 뒤에 놓고 뒤의 클립을 민다 |
| 리플 삭제 | 지운 클립이 있던 트랙만 당긴다 |
| 실행 취소 방식 | 편집마다 명령 클래스를 따로 만들지 않고, 편집 전후의 시퀀스 상태를 통째로 떠 두는 명령 하나(`SequenceEditCommand`)로 처리한다. 클립에 속성이 늘어도 실행 취소 코드를 고칠 필요가 없다 |
| 연결·그룹 | `ClipLink`·`ClipGroup` 클래스 대신 클립의 `linkId`·`groupId`로 표현한다 |
| 트랙 상태 | `TrackState` 클래스 대신 트랙의 `locked`·`hidden`·`muted`·`solo` 속성으로 표현한다 |
| 자동 감쇠 | 줄어들 트랙(BGM)에서 기준 트랙(내레이션)을 고른다. 기준 트랙에 클립이 있는 동안 줄이고 앞뒤 0.3초 동안 서서히 바뀐다 |
| 모노 소리 | 양쪽 채널에서 원래 크기로 낸다 |
| 편집 내용 저장 | 편집할 때마다 바로 저장한다 (자동 저장·복구는 M13) |
| 단축키 | 프리미어식: Space 재생, ←/→ 프레임 이동, Ctrl+K 또는 S 분할, Delete 삭제, Shift+Delete 리플 삭제, Ctrl+Z/Y, Ctrl+C/V/A, Ctrl+G 그룹, Ctrl+Shift+G 해제, I/O/L 반복 구간, M 마커 |
| 모듈 참조 | `NGL.Commands`가 `NGL.IO`를 참조한다 (상태를 떠 두는 데 저장 형식을 쓰기 때문) |
| 앱 대상 | `net10.0-windows10.0.19041.0` (SkiaSharp WPF 패키지의 요구) |
| FFmpeg | 9.0.2 공유 빌드 + FFmpeg.AutoGen 9.0.1.1 |
| 내보내기 인코더 | libx264(preset medium) + AAC 192kbps, BT.709 색 규격, 웹 재생용 faststart |
| 변형 속성 | 위치는 화면 가운데에서 옮긴 픽셀 수, 크기는 화면 맞춤 기준 10~400%, 회전은 시계 방향. 자르기는 가장자리별 비율이고 남은 부분을 다시 화면에 맞춘다 |
| 블렌드 모드 | 일반·곱하기·스크린·오버레이·더하기 |
| 속성 패널 입력 | 슬라이더 대신 숫자 칸을 쓴다 (Enter나 다른 곳 클릭으로 확정, 한 번에 하나의 실행 취소 단계) |
| 키프레임 방식 | `AnimatableProperty<T>`로 속성을 바꾸지 않고, 클립에 속성별 키프레임 목록(`keyframes`)을 덧붙였다. 키프레임이 없는 속성은 기존 값 그대로 쓴다. 키프레임의 시간은 클립의 시작에서 잰다 |
| 이징 | 일정하게·천천히 시작·천천히 끝·천천히 시작과 끝. 키프레임에서 다음 키프레임까지의 구간에 적용된다 |
| 애니메이션 프리셋 | `%AppData%/NGvid/animation-presets.json`에 저장. 기본으로 페이드 인·확대 등장·왼쪽에서 등장이 들어 있다 |
| 글자 스타일 | 텍스트 클립과 자막이 같은 스타일(글꼴·크기·굵게·색·외곽선·그림자·배경 박스·위치·단어 강조 색)을 쓴다. 색은 `#RRGGBB` 또는 `#AARRGGBB`로 적는다 |
| 기본 글꼴 | 맑은 고딕(Malgun Gothic). Pretendard는 내려받아야 해서 넣지 않았고, 설치되어 있으면 글꼴 목록에서 고를 수 있다 |
| 자막 기본 위치 | 화면 가운데에서 아래로 화면 높이의 36% |
| 텍스트 추가 | 재생 위치가 비어 있는 영상 트랙에 놓고, 없으면 맨 위에 새 영상 트랙을 만든다 |
| 스타일 프리셋 | `%AppData%/NGvid/text-style-presets.json`에 저장. 기본·팝업·박스가 들어 있고, 적용할 때 위치는 바꾸지 않는다 |
| 효과 방식 | 효과마다 클래스(`IVideoEffect`)를 쌓는 대신 영상·이미지 클립에 효과 값 묶음(`effects`)을 하나 둔다. 값이 0이면 그 효과는 꺼진 것이다. 색보정은 색 행렬, 흐림·선명은 Skia 필터, LUT만 셰이더를 쓴다 |
| 색보정 순서 | 노출 → 색온도 → 밝기 → 대비 → 채도 → LUT |
| 전환 | 뒤 클립의 속성이다. 뒤 클립의 처음 n초 동안 진행되고, 그동안 같은 트랙에서 바로 앞에 붙은 클립이 원본의 뒷부분(없으면 마지막 프레임)으로 계속 보인다. 앞 클립이 없으면 검은 화면에서 나타난다 |
| LUT 파일 | 프로젝트 폴더의 `luts/`로 복사하고 클립에는 상대 경로를 적는다 |
| 모듈 참조 | `NGL.Export`가 `NGL.IO`를 참조한다 (LUT 파일을 읽기 위해) |
| 내보내기 길이 | 시퀀스의 마지막 클립이 끝나는 곳까지 (소리만 더 길어도 그 끝까지) |
| 모듈 참조 | `NGL.Export`가 `NGL.Playback`을 참조한다 (미리보기와 같은 프레임·소리 공급 코드를 쓰기 위해) |

## 아직 정하지 않았거나 하지 않은 것

- `LICENSE` 파일(GPL-3.0)이 저장소에 없다.
- `NGvid_UI_mockups/`는 커밋하지 않았다. 공개 저장소에 올릴지 정해야 한다.
- 시작 창, 설정 창, 단축키 목록 창, 시퀀스 설정 창은 아직 없다.
- 보관함에서 원본을 삭제하는 기능이 없다.
- 타임라인에서 마우스로 영역을 끌어 여러 클립을 선택하는 기능이 없다 (Ctrl+클릭과 모두 선택만 있음).
